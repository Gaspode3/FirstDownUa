# Перша вниз — сайт firstdown.org.ua

Сайт збирається з одного шаблону в дві мовні версії (українська `/` та англійська `/en/`), щоб Google бачив текст обома мовами без JavaScript.

## Що редагувати

| Що змінити | Де |
|---|---|
| Тексти (UA та EN) | `translations.js` |
| Розмітка, стилі, скрипти | `src/index.template.html` |
| SEO-теги англійської версії (title, description) | словник `SEO_EN` у `build.py` |

**Не редагуйте вручну** `index.html`, `en/index.html`, `sitemap.xml`, `robots.txt` — вони створюються скриптом і перезаписуються.

## Як зібрати

```bash
python3 build.py
```

Потрібен лише Python 3.8+. Після збірки закомітьте змінені файли (`index.html`, `en/index.html`, `sitemap.xml`, `robots.txt`) разом із вашими правками.

Скрипт виводить попередження (рядки з `!`), якщо, наприклад, ключ є лише в одній мові або в шаблоні зник якийсь елемент.
